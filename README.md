# Dark Memories 🕯️

Пиксельная 3D Dark Fantasy браузерная игра: деревня → река → замок, осколки света, тени-стражники.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://127.0.0.1:5173/

## Управление

- WASD — идти, мышь — осмотр
- ЛКМ — удар факелом
- E — взять / возложить
- Space — прыжок, Shift — бег
- `[` / `]` — размер пикселя

## Цель

Найди 5 осколков света, принеси к алтарю во дворе замка, открой портал.

## Стек

Three.js + Vite + TypeScript. Все текстуры — процедурный пиксель-арт (canvas, NearestFilter).
