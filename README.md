# Dark Memories 🕯️

Пиксельная 3D Dark Fantasy браузерная игра: открытый регион — деревня, река с мостом,
замок с донжоном, Черное озеро с островом, скалы со смотровой, ферма, осадный лагерь.
Осколки света, тени-стражники, меч и факел.

## Запуск

```bash
npm install
npm run dev      # http://127.0.0.1:5173/
npm test         # vitest: проходимость, квест, состояния, бой
npm run build
```

## Управление

- WASD — идти, мышь — осмотр
- ЛКМ — удар
- 1 / 2 — меч / факел (меч сильнее, факел светит)
- E — взять / возложить
- Space — прыжок, Shift — бег
- `[` / `]` — размер пикселя (он же качество)

## Цель

Найди 5 осколков света (лежат в стороне от тропы), принеси к алтарю во дворе замка,
открой портал. Тени охраняют осколки и узкие места. Смерть — респаун в деревне,
осколки сохраняются.

## Стек

Three.js + Vite + TypeScript. Все текстуры — процедурный пиксель-арт
(canvas 16–64px, NearestFilter + мипмапы). Высота земли — единый источник правды
(`getGroundHeight`), коллизии — boxes/circles/steps, тест проходимости — BFS.
